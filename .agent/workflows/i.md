Цей workflow автоматизує процес реалізації наступного невиконаного завдання з файлу `TODO.md`.

1.  **Вибір завдання**:
    - Зчитай файл `TODO.md`.
    - Знайди перший невиконаний підпункт (рядок, що починається з `- [ ]` всередині поточної фази).
    - Це буде **ПОТОЧНЕ_ЗАВДАННЯ**.

2.  **Аналіз вимог**:
    - Зчитай файл `SPECIFICATION.md`.
    - Знайди розділи, що стосуються **ПОТОЧНОГО_ЗАВДАННЯ**.

3.  **Створення плану реалізації**:
    - Використовуй `write_to_file` для створення файлу `plans/Plan - [НАЗВА_ЗАВДАННЯ].md` на диску.
    - Включи в файл:
        - **Мета**: Що саме ми робимо.
        - **Зміни**: Перелік файлів та змін (API, структури).
        - **Тести**: План автоматичного тестування (unit tests, integration tests).
        - **Ручна перевірка**: Як перевірити результат вручну.

4.  **Запит на підтвердження**:
    - Використовуй `notify_user` для запиту підтвердження плану або його модифікації.

5.  **Створення тестів**:
    - Створи автоматичні тести згідно з планом.

6.  **Реалізація та Оновлення плану**:
    - Виконай модифікації коду згідно з планом.
    - Додай коментарі в `Plan - [НАЗВА_ЗАВДАННЯ].md` щодо деталей реалізації, проблем або прийнятих рішень.

7.  **Оновлення документації**:
    - Онови документацію коду (doc comments) або `README.md`, якщо це доречно.

8.  **Оновлення специфікації**:
    - Відкрий `SPECIFICATION.md`.
    - Додай коментарі або онови відповідні секції, відображаючи реальний стан речей після реалізації.

9.  **Завершення**:
    - Відкрий `TODO.md`.
    - Познач пункт як виконаний (`- [x] ...`).
    - (Опціонально) Виконай коміт змін.
