Якщо подивитися статистику наприклад щойно створеної черги у тимчасовому каталозі, то можна побачити там специфічні символи форматування, яких не повинно бути там. Наприклад:

```
     Running `target/debug/slint_kanban --root /tmp/kanban_sim1 stats`
== Загальний стан дошки ==
Всього тікетів: 0
Не призначено:  0
Сер. Lead Time: -
Сер. Cycle Time: -
Всього балів:    0
Готових балів:    0

== Тікетів у чергах ==
{:<20} {:>5} {:>6} {:>5}
1.Incoming               0      -     -
2.ToDo                   0     21    0%
3.Doing                  0      5    0%
4.Reviewing              0      -     -
5.Testing                0      -     -
6.Done                   0      -     -
7.Archive                0      -     -

== Тікетів у користувачів ==
{:<20} {:>5}
user                     0

== Trends (Debug) ==
Date         TotalT    DoneT   TotalP    DoneP

```

Символів `{:<20} {:>5} {:>6} {:>5}` та `{:<20} {:>5}` не повинно бути у виводі, бо вони лише засмічують вивід.

Необхідно сторити тест, який перевіряє статистику пустої черги на правильність, а потім виправити помилку.
