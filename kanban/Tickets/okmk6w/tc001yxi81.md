# План виконання: Fix Ctrl-M crash on toggle "show only mine"

## Проблема
При натисканні `Ctrl-M` програма падає з паником у `VecModel::remove()`:
```
removal index (is 2) should be < len (is 2)
```

## Корінь проблеми
Баг у `src/controller.rs:179-180` (метод `sync_board_data`):
```rust
for _ in 0..(current_len - new_len) {
    tickets_model.remove(current_len - 1); // index не змінюється при кожній ітерації!
}
```

Після кожного `remove(index)` довжина вектора зменшується на 1, тому фіксований індекс виходить за межі.

## Виправлення
Використовувати динамічний індекс: `tickets_model.remove(current_len - 1 - i)`, де `i` — лічильник ітерації.

## Тестування
- Додано тест `test_gui_toggle_show_only_mine_no_crash` в `src/gui_tests.rs`, який відтворює сценарій:
  - Створити 3+ тікетів в одній черзі
  - Увімкнути фільтр show_only_mine (фільтрує всі тікети)
  - Перевірити що не падає і фільтр застосовується коректно
