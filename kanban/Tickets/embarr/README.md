## Контекст

Зараз програма не підтримує мінімізацію в системний трей. При закритті вікна програма повністю закривається, що незручно для фонових користувачів.

Slint 1.17 додає `SystemTrayIcon`, що дозволяє створити іконку в системному треї з контекстним меню (відкрити вікно, вийти).

## Очікувана поведінка

1. Додати `SystemTrayIcon` з контекстним меню
2. Меню: "Відкрити", "Вийти"
3. При закритті вікна — мінімізувати в трей (або запитувати дію)
4. Додати опцію в настройки для заборони tray icon.

## Ризики

- `SystemTrayIcon` може не працювати на всіх платформах (Linux Wayland, macOS)
- Потрібно обробляти події системного трею

## Acceptance Criteria

- [ ] Програма має іконку в системному треї
- [ ] Контекстне меню містить "Відкрити" та "Вийти"
- [ ] При закритті вікна програма мінімізується в трей
- [ ] "Відкрити" з трей відкриває вікно
- [ ] "Вийти" повністю закриває програму
