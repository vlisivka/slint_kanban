Для уникнення дублювання коду, потрібно переглянути допоміжні функції у всіх файлах і обʼєднати спільні допоміжні функції з різних файлів у спільний файл для основного коду, і спільний файл для тестів. Потрібно задокументувати кожну функцію, щоб було легко зрозуміти її призначення, а також згадати про файли з цими допоміжними функціями в документації, щоб не створювати їх повторно.
