Для того, щоб пустий каталог, наприклад черга чи каталог з тікетами чи логами, зберігся в git, в ньому повинен бути хоча б один файл.

Потрібно зробити так, щоб в каталогах Queue, Tickets, та logs, можна було створювати файли .keepme (чи інші файли чи каталоги, які починаються з .), щоб вони ігнорувалися, і щоб вони не видалялися програмою slint_kanban.
