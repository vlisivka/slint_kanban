## Реалізація

Завдання виконано за допомогою вбудованих засобів Slint:

1.  **Новий компонент `IdCopy`**: Додано в `ui/common.slint`. Він використовує `TextEdit` в режимі `read-only` для відображення ID та підтримки методу `copy()`. Кнопка копіювання (📋) з'являється при наведенні миші.
2.  **Інтеграція в `TicketCard`**: Замінено статичний текст ID на компонент `IdCopy`.
3.  **Інтеграція в `TicketView`**: Додано блок `IdCopy` під заголовком тікета.
4.  **Інтеграція в `TicketEdit`**: Заголовок вікна редагування тепер містить клікабельний `IdCopy` для зручного копіювання під час редагування.

Всі зміни реалізовані тільки в `.slint` файлах, що дозволило уникнути нових залежностей в Rust та змін в системних колбеках.

### Автоматичні тести
- Оскільки `copy()` взаємодіє з системним буфером, автоматичне тестування в CI може бути обмеженим.
- Перевіримо, що `TextEdit` містить правильний текст через Slint-тести.

### Ручна перевірка
1.  Запустити додаток.
2.  Навести мишу на ID картки, натиснути кнопку копіювання, що з'явилася.
3.  Вставити (Ctrl+V) у текстовий редактор. Має з'явитися `#xxxxxx`.
4.  Повторити для вікон перегляду та редагування.
