# Plan - Completion rate calculations

## Мета
Реалізувати обчислення відсотка завершення (Completion Rate) для дошки та поточного спринта. Це дозволить оцінити прогрес роботи над проектом та ефективність виконання спринтів.

## Аналіз метрик
1. **Загальний відсоток завершення (Board Completion)**:
   - Формула: `(Кількість тікетів у чергах "Done") / (Загальна кількість тікетів — тікети в "Archive") * 100`.
   - Це показує, скільки активних завдань уже виконано.
2. **Відсоток виконання спринта (Sprint Completion)**:
   - Формула: `(Тікети, що потрапили в "Done" під час спринта) / (Тікети, що були активні під час спринта) * 100`.
   - "Активні під час спринта" — тікети, що були створені або переміщені в межах дат спринта.

## Зміни
### 1. Model (`src/model/stats.rs`)
- Оновити структуру `BoardSummary`:
  ```rust
  pub struct BoardSummary {
      // ... існуючі поля ...
      pub completion_rate: Option<f64>,
      pub sprint_completion_rate: Option<f64>,
  }
  ```
- Оновити `get_board_summary`:
  - Використати `done_queues` для визначення завершених тікетів.
  - Розрахувати `completion_rate` на основі поточного стану черг.
  - Якщо лог доступний і є часовий діапазон (для спринта), розрахувати `sprint_completion_rate`.

### 2. CLI (`src/main.rs`)
- Оновити вивід команди `stats`:
  - Додати рядок "Completion Rate: XX.X%".
  - Якщо вибрано спринт, додати "Sprint Completion: XX.X%".

### 3. UI (`ui/common.slint` & `ui/stats_view.slint` & `src/main.rs`)
- Додати поля `completion_rate: string` та `sprint_completion_rate: string` до `BoardSummaryStr`.
- Оновити логіку синхронізації в `src/main.rs` (конвертація `f64` у відсотки).
- Оновити `StatsView` для відображення цих значень.

## Тести
- **Unit-тести (`src/model/tests/stats_tests.rs`)**:
  - Тест на розрахунок `completion_rate` з різними наборами тікетів.
  - Тест на розрахунок `sprint_completion_rate` на основі мокованих логів (створення + перехід у Done).
- **CLI-тести**: Перевірити наявність відсотків у виводі `slint_kanban stats`.

## Ручна перевірка
1. Створити кілька тікетів.
2. Перемістити частину в "Done".
3. Запустити `slint_kanban stats` і перевірити "Completion Rate".
4. Відкрити GUI -> Statistics і перевірити відображення.
5. Додати спринт, перемістити тікет у Done в межах спринта, перевірити "Sprint Completion".
