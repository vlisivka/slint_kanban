# План реалізації: Статистика — Snapshot-метрики (Ticket count per queue)

## Мета
Реалізувати першу фазу системи статистики (Snapshot-метрики), згідно з проведеним дослідженням. Вона дозволить отримувати поточну зведену інформацію про дошку (кількість тікетів по чергах та по користувачах) без необхідності парсингу журналів. Результат буде виводитися через нову CLI-команду `stats`.

Це покриває пункт TODO: `Ticket count per queue` (та базово готує архітектуру для всього `analytics dashboard`).

## Зміни (Архітектура та Код)

1. **`src/model/mod.rs`**:
   - Експортувати новий модуль: `pub mod stats;`.

2. **`src/model/stats.rs`** (Новий файл):
   - Створити структуру `BoardSummary`, яка описуватиме поточний стан дошки.

3. **`ui/app.slint` та `ui/`**:
   - Додати кнопку `📊 Statistics` у верхній панелі керування (toolbar), поруч із дошкою/інформацією.
   - Створити `StatsView` (у новому файлі `ui/stats_view.slint` або в `ui/app.slint`) — екран на весь вікно, що показує зведену текстову статистику (таблицею або списком): 
     - Загальна кількість тікетів.
     - Кількість тікетів по кожній черзі.
     - Кількість тікетів по користувачах.
   - Створити структури: `QueueStatStr`, `UserStatStr`, `BoardSummaryStr`. Передавати ці дані через глобальний стан або Property в UI.
   - Додати callback `show_stats()`, який буде викликати перемальовування та відкривати `StatsView`.
   - В UI додати можливість перемикатись з `StatsView` назад до `BoardView`.

4. **`src/cli.rs`**:
   - Додати нову підкоманду до `enum Commands`: `Stats`.

5. **`src/main.rs`**:
   - Розширити `into_slint_summary` для перетворення `BoardSummary` в структури для Slint.
   - Додати `ui.on_show_stats(...)` до `init_callbacks()`, який завантажить статистику і передасть в UI.
   - У `handle_command` додати обробник `Commands::Stats` для CLI-виводу.

## Тести

1. **Unit tests (`src/model/tests/stats_tests.rs`)**:
   - Створити `test_get_board_summary`.

2. **CLI tests (`src/main_tests.rs`)**:
   - Додати `test_cli_stats`.

3. **GUI tests (`src/gui_tests.rs`)**:
   - Додати `test_gui_stats_view_opens` — перевірити знаходження кнопки "Statistics", клік по ній та зміну поточного view на статистику.
   - Знайти елементи, які містять рядок з `Total tickets`, щоб переконатись, що статистика відображається в GUI.

## Ручна перевірка

1. Скомпілювати та запустити CLI: `cargo run -- stats`.
2. Запустити GUI `cargo run`, натиснути кнопку `📊 Statistics` у тулбарі.
3. Пересвідчитись, що цифри в CLI та GUI однакові та відповідають реальній кількості тікетів на дошці.
